# Samples (synthetic)

Everything in this folder is **made up** and harmless. It was generated by
[`tools/generate_samples.py`](tools/generate_samples.py) and contains no real telemetry:

- hosts and users are fictional (`WS-ALICE-01`, `CORP\alice`, ...);
- IP addresses come from the documentation ranges `192.0.2.0/24`, `198.51.100.0/24` and
  `203.0.113.0/24` (RFC 5737) plus private `10.x` addresses;
- host names use `example.com` / `example.net`;
- command lines are fake, and the only `-EncodedCommand` payload decodes to
  `Write-Output 'edr-agent demo: simulated download cradle'`;
- `Hashes` values are SHA-256 digests of the image *path string*, not of any file.

Regenerate with `python3 samples/tools/generate_samples.py`; CI runs it with `--check` so the
committed files always match the generator.

## Files

| File | What it is |
|---|---|
| `scenario_*.jsonl` | Normalized events (the agent's replay / wire format), one JSON object per line |
| `sysmon_xml/scenario_*.xml` | The Sysmon-sourced events of each scenario rendered as `EvtRender` XML; the C++ tests parse these and require exactly the same events as the `.jsonl` file |
| `baseline.json` | Known (host, image, destination IP) pairs for the anomalous-outbound check |
| `rule_cases.jsonl` | One or more positive and negative cases per rule, run by both the C++ and Python tests |

## Scenarios and expected outcomes (with `baseline.json`)

| Scenario | Host | Story | Expected result |
|---|---|---|---|
| 1 `benign_admin_day` | SRV-FILES-01 | An admin opens Services, runs Robocopy, browses intranet and known sites, edits a spreadsheet | No signals, no incident |
| 2 `phishing_chain` | WS-ALICE-01 | Outlook opens a macro document; Word starts PowerShell with `-EncodedCommand`, which connects to `203.0.113.50:8443` (not in the baseline) | One incident, score 100, critical |
| 3 `runkey_persistence` | WS-CAROL-03 | A helper extracted to `AppData\Local\Temp` writes a `CurrentVersion\Run` value; no network | One incident, score 55, medium |
| 4 `lolbin_download` | WS-BOB-02 | `cmd` runs `certutil -urlcache` against `192.0.2.80` (configured as an untrusted range) | One incident, score 60, high |
| 5 `low_severity_noise` | WS-DAVE-04 | Helpdesk discovery commands, a CDN with random-looking names, an updater in Temp | 13 low-severity signals in 4 process trees, highest tree score 20, **no incident** |

Without `baseline.json`, first-seen destinations add anomalous-outbound signals: scenario 5
then produces two medium incidents and scenario 1 still produces none.
